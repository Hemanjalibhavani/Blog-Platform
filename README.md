# ✍️ BlogSphere – Modern Blog Platform

An engaging and responsive **modern blog platform** developed using
**HTML5, CSS3, and Vanilla JavaScript**.

The application allows users to create, publish, edit, delete, search,
like, and comment on blog posts. It also includes user authentication,
category filtering, dark mode, responsive design, and browser-based
data persistence using LocalStorage.

The project is designed to provide a clean, interactive, and
user-friendly blogging experience while demonstrating modern
frontend web development concepts.
